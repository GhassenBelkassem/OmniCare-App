## 4. The pencil

**Where A2 renders it** (`feature/g2.1`, `presentation/patient_passport_screen.dart`):
- `_buildPassportContent` → `PassportHeader(onEdit: _editorSubject == null ? null : _openEditor, …)`.
- `PassportHeader` (`widgets/passport_header.dart`) draws `Icons.edit_outlined` only when `onEdit` is not null.

**Every condition that hides it on `feature/g2.1`** (`_editorSubject` returns null):
1. No `MedicalDataEditorFactory` provider (`context.read` throws, caught → `_editorFactory = null`).
   `feature/g2.1`'s `lib/main.dart` always provides it (`Provider<MedicalDataEditorFactory>.value`, line 335).
2. A family member is selected and has no `familyMemberId` (null or blank).
3. Otherwise it shows: the holder gets `SelfRecordSubject`, a family member with an id gets `FamilyRecordSubject(id)`.

So on `feature/g2.1`, a new account (holder selected by default) sees the pencil.

**Why it doesn't show on `main`:** `main`'s `_buildPassportContent` builds
`PassportHeader(selectedMember:…, onSelectPassport:…, onShare:…)` with **no `onEdit`**, under the comment
« The edit pencil stays hidden until the editor is wired to the record (G2-FT-3 decision 4; a later
G-2.1 step) ». `main` also has no `MedicalDataEditorFactory` or editor view model. Hidden for every
account, new or not. Nothing was removed: A2 never reached `main`.
